NOVA | Web Application Designer Portfolio

A clean and minimal static web interface built using HTML5 and CSS3, focused on simplicity, responsiveness, and cross-browser compatibility.

**Live Demo**
https://preethikasuburamani.github.io/Black-and-White-responsive-cross-browser-compatible-interfaces/index.html

**Overview**
This project showcases a black-and-white themed UI designed to work seamlessly across different screen sizes and browsers. The goal was to keep the design lightweight while maintaining a modern and consistent user experience.

**Features**
-Fully responsive layout
-Cross-browser compatible
-Minimal black & white design
-Built with pure HTML5 & CSS3 (no frameworks)
-Tech Stack
-HTML5
-CSS3

**Purpose**
Created as a practice project to strengthen fundamentals in responsive design and clean UI development without relying on external libraries.

 **Project Structure**
home.html: The landing page with a hero introduction.
portfolio.html: A gallery section for visual project displays.
services.html: A breakdown of professional services offered.
about.html: Detailed information about my design approach and background.
contact.html: A contact form and social media links.
